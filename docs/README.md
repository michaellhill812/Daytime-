# The field guide

`daytime-guide.html` is the source of the published Daytime Field Guide:

**https://claude.ai/code/artifact/d645ba04-afed-4048-b451-7d62c864d52d**

`daytime-guide.txt` is the same content as plain prose, for pinning to the Wall
where the styling would be lost anyway.

Neither is part of the app. They are not built, not served, and not imported —
they live here so the source of a published document isn't only in one
session's scratchpad.

## Editing it

Edit `daytime-guide.html`, then republish **to the same URL** — passing a new
path or omitting the URL creates a second artifact rather than updating this
one. Keep the `<title>` and the favicon stable; readers find the page by them.

Two things that are easy to forget:

- **The two files have to move together.** The plain-text copy is the same
  document; a section added to one belongs in the other.
- **A published artifact does not update for its viewers on its own.** After
  republishing, move the share pin from the page's share menu, or everyone who
  has the link keeps seeing the version that was pinned.

## It describes real behaviour

The guide claims things about the app — what the ring means, what the hub's
number is counting, what colour says what. Those claims go stale when the app
changes, and a wrong guide is worse than no guide. The ring section has already
had to be rewritten once, when the arc flipped from measuring finished work to
measuring open work. If a change alters what someone *sees*, check this file.
